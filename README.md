# Recruitment Assistant Agent – Resume Screening Module

This project implements Agent 1 of a multi-agent Recruitment Assistant system.

## Agent 1: Resume Screening Agent
- Evaluates resumes against job descriptions
- Returns structured, explainable scores
- Uses strict schemas and validation
- Designed with safety and cost controls

## Features
- Deterministic LLM usage
- JSON schema validation
- Clear error handling
- Test coverage
